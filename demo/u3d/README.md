# Unity demos

- [u3d_mocap](u3d_mocap): the original minimal motion-receiving example for Unity 2019.4.
  Use the repository's existing SDK installation instructions.
- [PN Link Visualizer](pnlink_visualizer): the versioned visualizer demo for Unity
  6000.0.31f1, with calibration guidance, live device status, Chinese/English UI and
  local skeletal recording/replay. Product version: **0.8.0**; tag:
  **pnlink-visualizer-v0.8.0**. This demo includes its tested SDK pair.

The projects and versions are independent. The original example and the repository's
SDK installation script are preserved.
